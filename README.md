## 我在做什麼

這些專案有個共同點：先有問題，才有程式。

當爸爸之後才寫育兒工具，找工作時才做面試 Bot，想理財才做選股器。比起做一個很厲害的框架，我更在意能不能真的幫到一個人——通常那個人是我自己。

目前持續在補的：RAG 檢索品質、Agent 的人工審核流程設計，以及怎麼把這些東西做得讓非工程師也敢用。
